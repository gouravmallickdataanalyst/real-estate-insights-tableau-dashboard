# 🏠 Real Estate Insights Dashboard – Tableau
## 📊 Project Overview
The Real Estate Insights Dashboard is an interactive Tableau data analytics project designed to analyze real estate sales performance across towns, property types, and time periods.
The dashboard transforms property transaction data into interactive visual insights that can support regional performance analysis, property segmentation, and data-driven decision-making.
---
## 🎯 Business Objective
The objective of this project is to:
- Analyze sales performance across different towns
- Identify high-performing and lower-performing locations
- Understand property type distribution
- Analyze sales trends over time
- Compare sales ratios across towns and property categories
- Provide an interactive dashboard for business users

## 📌 Dashboard Features
### 1. Town-wise Sales Analysis
A horizontal bar chart compares sales performance across towns and helps identify locations with higher sales values.
### 2. Sales Trend Analysis
A time-series visualization tracks the selected metric across months, allowing users to identify changes in sales activity over time.
### 3. Geographic Sales Analysis
The map visualization displays sales distribution geographically, allowing users to explore regional performance.
### 4. Property Type Distribution
The pie chart provides a view of the composition of recorded properties across different property categories.
### 5. Sales Ratio Heat Map
The heat map compares towns against residential/property types to identify differences in sales ratios.
### 6. Property Segment Analysis
The treemap provides a compact comparison of property categories and their contribution to the dataset.
---
## 🎛️ Interactive Filters & Controls
The dashboard includes:
- Property Type
- Sale Year
- Town
- Date Recorded
- Metric Parameter
The Metric Parameter allows users to dynamically change the metric displayed across selected visualizations.

## 📈 Key Insights
Based on the dashboard:
- The highest town-level sales value displayed is approximately **9.63 billion**.
- **Single Family** properties account for **273,147** records, making them the largest visible property category.
- **Residential** properties account for approximately **112,099** records.
- **Condo** properties account for approximately **68,789** records.
- Several other high-performing towns show sales values in the approximate **4.2–4.9 billion+** range.
- The property distribution indicates a strong concentration in a few major property categories.
> Note: These insights are based on the values displayed in the Tableau dashboard.
